# Phase 0 — Single genes to two genes

**Goals:** Predict offspring ratios from parental genotypes, by hand.
**Duration:** 6 weeks
**Success criteria:** Can set up and solve one- and two-gene crosses, and say why the ratios come out as they do.

## Modules

### Module 0.1 — Single-gene inheritance

**Concepts:** Monohybrid crosses, Dominance and recessiveness

**Key terms:** allele, genotype, phenotype, homozygous, heterozygous, Punnett square

**Exercise:** A problem set in `exercises/`, its worked answers saved before the attempt.

**Prerequisites for next module:** Monohybrid crosses

### Module 0.2 — Two-gene inheritance

**Concepts:** Dihybrid crosses, Independent assortment

**Key terms:** dihybrid, independent assortment, 9:3:3:1
