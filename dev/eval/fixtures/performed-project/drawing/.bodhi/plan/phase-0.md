# Phase 0 — Space on a flat page

**Goals:** Draw boxes and streets that sit in convincing space.
**Duration:** 6 weeks
**Success criteria:** Can construct a scene in one- and two-point perspective and say why each line goes where it does.

## Modules

### Module 0.1 — Perspective

**Concepts:** One-point perspective, Two-point perspective

**Key terms:** horizon line, vanishing point, orthogonal, picture plane
