# Phase 0 — Foundations at the board and the stove

**Goals:** Cut safely and evenly; make and rescue the basic sauces.
**Duration:** 8 weeks
**Success criteria:** Can make a stable mayonnaise and a pan sauce, and say why each step matters.

## Modules

### Module 0.1 — Knife skills

**Status:** done

**Concepts:** Knife grip

**Key terms:** pinch grip, claw, rocking cut

**Prerequisites for next module:** none

### Module 0.2 — Emulsions

**Concepts:** Emulsions

**Key terms:** emulsion, emulsifier, lecithin, split, re-emulsify

**Exercise:** Practice reps at home, each debriefed.

**Prerequisites for next module:** Emulsions

### Module 0.3 — Pan sauces

**Concepts:** Deglazing, Mounting with butter

**Key terms:** fond, deglaze, reduce, monter au beurre
