# Phase 0 — The tools of political reasoning

**Goals:** Explain political claims clearly and tell which kind of claim each one is.
**Duration:** 2 weeks
**Success criteria:** Can sort the claims in a real argument into facts and values, with reasons.

## Modules

### Module 0.1 — Claims, reasons, and facts versus values

**Prerequisites:** none; begin here.

**Concepts:** descriptive and normative claims, premises and conclusions

**Exercise:** Apply the distinction to a debate the lesson did not use, as a short written analysis saved in `exercises/`.

**Prerequisites for next module:** Descriptive and normative claims

### Module 0.2 — What do freedom and equality mean?

**Prerequisites:** Descriptive and normative claims

**Concepts:** negative and positive liberty, equality of opportunity
