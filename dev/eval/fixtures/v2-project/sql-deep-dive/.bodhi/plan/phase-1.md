# Phase 1 — Foundations to internals

**Goals:** Read and reason about real query behavior.
**Duration:** 6 weeks
**Success criteria:** Can explain and predict planner choices on a real schema.

## Modules

### Module 1.1 — Schema Design
Normalization, trade-offs, real-world denormalization.

### Module 1.2 — Indexing
B-trees, clustered vs non-clustered, covering indexes.

**Prerequisites for next module:** B-tree indexes, Query planning

### Module 1.3 — Query Optimization
EXPLAIN, planner cost model, join strategies.
